# Whimsical AI City Game

A friendly modern-city game where players improve AI instructions to repair civic mistakes, build new projects, and learn how model behavior changes.

## Language

**City**:
Whimsical modern setting that makes learning progress visible through construction, repair, and growth.
_Avoid_: Village, fantasy world, town, dashboard

**Prompt Quest**:
Required challenge where a player improves a vague prompt until its result satisfies a clear goal and advances city restoration.
_Avoid_: Lesson, level, exercise

**Side Quest**:
Optional challenge that expands one AI concept without blocking core City progression.
_Avoid_: Bonus lesson, optional level

**Parameter Trial**:
Side Quest comparing one live sampling parameter across a creative civic task and a consistency-sensitive civic task.
_Avoid_: Temperature tutorial, settings screen, parameter quiz

**Player**:
Adult AI beginner using the public hackathon prototype and learning through experimentation and immediate consequences. Support for minors belongs to a future safety and compliance phase.
_Avoid_: Student, learner, user

**Mayor**:
Player's in-world role: a newly arrived civic leader responsible for building and repairing the City.
_Avoid_: Prompt Mage, wizard, guild artisan

**Construction Sprites**:
Cute civic work crew that interprets Mayor's prompts literally and turns them into visible City changes.
_Avoid_: AI assistant, magical architect, builders

**Civic Project**:
Visible city improvement shaped by a Prompt Quest, such as constructing a building or repairing damaged infrastructure.
_Avoid_: Generated image, response, output

**Citizen Request**:
Concrete civic need whose explicit and implicit requirements give a Prompt Quest its goal.
_Avoid_: Villager request, assignment, task description, user story

**Project Brief**:
Pinned checklist of citizen needs discovered before prompting Construction Sprites.
_Avoid_: Requirements panel, quest log, rubric

**Prompt Attempt**:
One typed or spoken instruction sent to Construction Sprites, producing visible Civic Project changes and Quest Feedback.
_Avoid_: Submission, answer, API call

**Prompt Blueprint**:
Beginner framework revealed after first failed Prompt Attempt: Goal, Context, Constraints, and Output.
_Avoid_: Prompt formula, magic words, prompt score

**Repair Stage**:
Visible partial improvement produced when a Prompt Attempt satisfies one or more Project Brief needs.
_Avoid_: Score tier, checkpoint, partial success

**Quest Feedback**:
Combined citizen reaction, requirement checklist, and one actionable hint following a prompt attempt.
_Avoid_: Score, grading, error message

**Playful Redirect**:
Quest Feedback for an off-topic Prompt Attempt; Construction Sprites ask for a civic instruction and leave City unchanged.
_Avoid_: Rejection, moderation error, invalid input

**Prompt Mishap**:
Comic City defect caused by a vague previous-mayor instruction and repaired through a Prompt Quest.
_Avoid_: Failure, bug, disaster

**District**:
Region of City grouping Civic Projects around a learning theme; completing one district reveals another.
_Avoid_: Chapter, world, module
