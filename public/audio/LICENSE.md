# Audio license

Every audio file in this directory comes from an existing OpenGameArt asset whose creator released it under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

CC0 permits copying, modification, distribution, and commercial use without attribution. `SOURCES.md` still records creators, source pages, original filenames, and checksums for auditability.

No Animal Crossing recording, composition, sound effect, or game asset is included.
